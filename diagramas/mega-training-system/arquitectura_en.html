Multi-discipline Flask application for AI-powered training plan generation using the Claude API. 4-layer architecture: Presentation → Application (Blueprints) → Services → Data. IC and MG are independent packages (src/ic/, src/mg/) each with their own Blueprint. app.py contains 9 global routes, DI container bootstrap (AppContainer) and dynamic plugin registration via discipline_registry.py. Sprint 4 adds: plugin system, DI with dependency-injector, api_v1_bp (/api/v1/), idempotency + result persistence, circuit breaker for Claude API, and env check at startup. Sprint 8+9 adds: Security layer — src/auth.py (opt-in API key auth), src/rate_limiter.py + src/rate_limit_middleware.py (sliding-window per-IP rate limiting), src/logging_config.py (idempotent centralized logging), src/app_factory.py (DRY shared middleware registration), PEP 562 lazy __getattr__ in discipline_registry, Sprint 10 adds: staff login system (auth_user/ package, Flask signed-cookie sessions, auth_cli.py offline CLI), admin panel at /admin/users, auth.py rewritten as always-on with TESTING bypass, FLASK_SECRET_KEY session support. and TYPE_CHECKING decoupling in discipline_protocol. Hexagonal (ports & adapters): secondary ports ClassStoragePort (IC) and KnowledgeBasePort (MG) with filesystem adapters — services are now fully Flask-free and filesystem-free under test injection.

New patterns introduced in Sprint 8+9 / Hexagonal

PEP 562 — Module-level __getattr__

discipline_registry.py uses __getattr__(name) at module level. CLASS_FILENAME_RE and CLASS_MP3_RE are computed only on first attribute access — _plugins_cache = None at import time means zero discovery cost until a consumer actually needs the regex.

AttributeComputed from
CLASS_FILENAME_REbuild_filename_re(get_plugins(), "json")
CLASS_MP3_REbuild_filename_re(get_plugins(), "mp3")

Decorator order — @rate_limited() + @inject

The order of decorators on Flask endpoints with both rate limiting and DI is critical. @inject annotations live on the inner function; functools.wraps preserves them so DI resolves correctly. Rate check runs before dependency injection.

OrderDecoratorReason
1 (outer)@bp.route(...)Flask route registration
2@rate_limited()Runs first at call time — rejects before DI
3 (inner)@injectDI resolves only if rate check passes

TYPE_CHECKING — runtime Flask decoupling

discipline_protocol.py moves from flask import Blueprint inside an if TYPE_CHECKING: block. At runtime the import never executes — the Protocol annotation is a string forward reference. This makes DisciplinePlugin usable in contexts where Flask is not installed (e.g., CLI tools, type-check-only environments).

Startup security order

register_shared_middleware() must be called after container.wire() so that @inject decorators in src.api are patched before api_v1_bp is registered. Auth and request logging hooks are registered in the same call for DRY consistency.

StepAction
1configure_logging() — before everything
2_init_container() + _init_plugins()
3container.wire(modules=[...])
4register_shared_middleware(app, container)

Idempotency + Result Persistence (Sprint 4)

Generation endpoints accept the Idempotency-Key header. If the key already exists in tasks.db, they return {task_id, cached: true} without launching a new task. On completion, the result (done/error + payload) is persisted in TaskResultStore with TTL 24h and is retrievable via GET /api/v1/tasks/<id>/result even after the SSE stream has closed.
