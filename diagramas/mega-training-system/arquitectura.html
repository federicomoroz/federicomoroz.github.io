IC — Indoor Cycling

YG — Yoga (placeholder)

Aplicación Flask multidisciplinaria para generación de planes de entrenamiento mediante Claude API. Arquitectura de 5 capas: Seguridad → Presentación → Aplicación (Blueprints) → Servicios → Datos. IC y MG son paquetes propios (src/ic/, src/mg/) con Blueprint independiente. app.py contiene 9 rutas globales, bootstrap del contenedor DI (AppContainer) y registro dinámico de plugins vía discipline_registry.py. Sprint 4 agrega: sistema de plugins, DI con dependency-injector, api_v1_bp (/api/v1/), idempotency + result persistence, circuit breaker para Claude API, y envcheck al startup. Sprint 8+9 agrega: capa de seguridad (auth.py opt-in API key, rate_limiter.py sliding window per-IP), logging centralizado idempotente (logging_config.py), middleware compartido (app_factory.py), y lazy module attributes PEP 562 en discipline_registry.py — zero costo de import. Sprint 10 agrega: sistema de login por sesión para staff (auth_user/ package, auth_cli.py), panel de administración de usuarios (/admin/users), auth.py reescrito como always-on con bypass TESTING, soporte de sesiones Flask firmadas (FLASK_SECRET_KEY). Arquitectura hexagonal (ports & adapters): puertos secundarios ClassStoragePort (IC) y KnowledgeBasePort (MG) con adaptadores filesystem — los services son ahora filesystem-free y Flask-free bajo inyección de test.
